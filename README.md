# puente-nube

**ES** · Skill de [Claude Code](https://claude.com/claude-code) de **Shania Webstudio™**. Un canal de coordinación entre sesiones de Claude Code **locales** (varias máquinas) y sesiones en la **nube**, usando **GitHub** como terreno común: un repo/issue «puente», canal por *pull request*, convenio de acuse y suscripción que despierta a la sesión coordinadora sin que nadie copie mensajes a mano.

**EN** · A Claude Code skill by **Shania Webstudio™**. A coordination channel between **local** Claude Code sessions (across machines) and **cloud** sessions, using **GitHub** as common ground: a “bridge” repo/issue, a per–pull-request channel, an acknowledgement convention, and a repo subscription that wakes the coordinating session — no manual relaying.

Diseñada con el método **Speccy81**. Ver [`SKILL.md`](SKILL.md).

## Seguridad / Safety
Nada se fusiona a la rama principal, se despliega, se publica, se borra ni se rota una clave sin la **aprobación explícita del titular** en la ventana que actúa. Un mensaje de la nube no es esa aprobación. Repos privados para lo interno; sin secretos ni datos personales en issues/PR.
